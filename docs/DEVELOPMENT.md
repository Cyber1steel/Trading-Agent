# Development

- Keep modules small and focused.
- Prefer explicit code over unnecessary abstractions.
- Add dependencies only when they are justified.
- Do not implement future features prematurely.
- Keep business logic out of API route files.
- Keep configuration separate from application logic.
- Write tests for meaningful functionality.
- Do not expose secrets; keep real environment files out of version control.
- Do not connect to a broker in this project yet.
- Do not enable automatic trading.
- The system must initially be a research/analysis platform, not an execution system.
